# Shipment Forecasting Model (ML + Time Series)

## 📌 Project Overview
This project predicts monthly shipment volumes using historical shipment data and backlog information.

## 🚀 Models Used
- ARIMA (baseline time-series model)
- Random Forest Regressor
- XGBoost Regressor

## ⚙️ Techniques
- Time-series feature engineering (lags, rolling averages, seasonality)
- Hyperparameter tuning using RandomizedSearchCV
- Time-aware train-test split
- Ensemble forecasting

## 🧰 Tech Stack
Python, Pandas, Scikit-learn, XGBoost, Statsmodels, Matplotlib

## 📊 Output
- Forecasted shipments for upcoming months (Sep–Dec)
- Model comparison using MAE and RMSE
